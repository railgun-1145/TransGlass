# TransGlass-cursor-

这个仓库包含 `TransGlass` 主项目，以及一些辅助脚本文件。

## 目录说明

- `TransGlass/`：Rust 编写的 Windows 窗口透明度与置顶管理工具。
- `sort_simulation.py`、`transparency_tool.py`、`vrc_migrator.py`：仓库中的辅助脚本。

## TransGlass 快速开始

1. 进入主项目目录：
   - `cd TransGlass`
2. 构建：
   - `cargo build --release`
3. 运行：
   - `target/release/transglass.exe`
