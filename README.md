# TransGlass

轻量级 Windows 窗口透明度与置顶管理工具。

## 🚀 快速开始

1. **构建**: 
   ```bash
   cargo build --release
   ```
2. **运行**: 
   运行 `target/release/transglass.exe`。
3. **管理**:
   - 程序启动后将显示控制面板，点击关闭按钮将自动隐藏到系统托盘。
   - 左键点击托盘图标重新打开面板。
   - 右键点击托盘图标可进行一键还原或安全退出。

## ⌨️ 默认快捷键

| 功能 | 快捷键 |
| :--- | :--- |
| **增加透明度** | `Alt + Z` |
| **减少透明度** | `Alt + X` |
| **切换窗口置顶** | `Alt + T` |
| **切换鼠标点透** | `Alt + P` |
| **切换笔点透** | `Alt + Shift + P` |
| **切换输入模式** | `Alt + Shift + M` |
| **还原当前窗口** | `Alt + R` |
| **还原所有窗口** | `Alt + Shift + R` |
| **重载热键配置** | `Alt + Shift + C` |
| **检查软件更新** | `Alt + U` |

## 🖥️ 命令行参数

| 参数 | 作用 |
| :--- | :--- |
| （无） | 正常启动，面板 + 系统托盘常驻 |
| `--quit` | 让**已在运行**的实例优雅退出（不会新开进程、也不会多留托盘图标）；没在运行则什么都不做 |
| `--self-test` | 跑一遍环境自检，不进 GUI；退出码 `0` = 无失败项、`1` = 有失败项 |
| `--self-test --strict` | 严格模式：有警告项时退出码为 `2`，可直接当 CI / 部署前门禁 |

### 自检能查什么

`--self-test` 会逐项探测并输出 `[PASS]/[WARN]/[FAIL]`，同时写一份日志到程序目录的 `transglass_selftest.log`（写不进去会退到 `%LOCALAPPDATA%\TransGlass\`）：

- **单实例**：有没有别的 TransGlass 在跑
- **配置文件**：能否解析（自动剥 UTF-8 BOM）、键名是否合法、有没有两个功能抢同一个组合键
- **热键注册**：逐槽位真实 `RegisterHotKey`，直接报出"被其它程序占用（1409）"——这是"热键没反应"最常见的根因
- **鼠标钩子** `WH_MOUSE_LL`、**键盘钩子** `WH_KEYBOARD_LL`：能否安装（关系到点透和热键优先模式）
- **运行环境**：是否管理员、DPI 感知级别、显示器数量、程序目录是否可写

> 热键"没反应"时先跑一次自检，能直接区分「被占用 / 被安全软件拦 / 配置写坏」三类问题。

## ⚙️ 自定义配置

你可以通过修改程序同级目录下的 `transglass_hotkeys.json` 来自定义热键与鼠标侧按键绑定（适配数位板/侧键笔）。修改后使用"重载热键配置"即可生效。

### 热键优先模式（强占组合键）

`RegisterHotKey` 是**先到先得**的：如果别的程序先占住了 `Alt+Z`，TransGlass 就注册不上。

打开配置里的 `"hotkey_priority": true`（或在面板上勾选**「快捷键优先（强占组合键）」**）后，程序改用低级键盘钩子 `WH_KEYBOARD_LL` 抢先拦截已配置的组合键，即使被别的软件占用也能生效：

- 只拦截配置里那几个组合键，其它按键原样放行，打字不受影响
- 长按只触发一次（与系统热键行为一致）
- 钩子被安全软件拦截时会自动退回普通注册模式，并在面板横幅里提示

默认 `false`。开启后会**全局吞掉**这些组合键（包括你在别的软件里想用同一个键时），属于"强占"语义，按需开启。

### 数位板/侧键笔建议

- 如果你的数位板驱动支持把笔的侧键映射为 `XButton1 / XButton2`，本工具可直接识别并执行动作。
- 默认行为：`XButton1` 降低透明度，`XButton2` 增加透明度（可在配置文件里改成 `toggle_click_through`、`toggle_topmost` 等）。

### 点透模式说明

- "鼠标点透 / 笔点透"用于控制透明窗口是否允许对应输入穿透到下层窗口。
- 取决于数位板驱动/应用的输入模式，笔事件有可能被系统当作普通鼠标事件；此时"笔点透"与"鼠标点透"的区分可能不生效。

### 配置写坏会怎样

配置文件解析失败时，程序**不会**直接覆盖你的文件：先把原文件改名备份成 `transglass_hotkeys.json.broken-<时间戳>.bak`，再写一份默认配置，并在面板顶部横幅里显示备份路径。热键注册失败（被占用/键名非法）同样会出现在横幅里，不再静默失败。

## 🧾 退出与托盘

- 面板右上角 `🗙 隐藏` 只是收进托盘，进程继续运行。
- 要真正退出：托盘右键菜单「退出程序」，或命令行 `transglass.exe --quit`。
- 退出时会显式删除托盘图标并还原所有被改过的窗口，不会在通知区域留残影。
- 若进程被任务管理器强制结束，通知区域仍可能留下一个"死图标"（Windows 行为），鼠标悬停一下即可清除。

## 📦 打包安装

1. 确保已安装 [Inno Setup](https://jrsoftware.org/isinfo.php)。
2. 运行 `cargo build --release`。
3. 使用 Inno Setup 编译 `TransGlass.iss` 即可生成标准安装程序。
